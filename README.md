# Nuga CS Demo

Разбор матчей CS2 с FACEIT: рейтинг игроков, хайлайты, экономика, хитмапы и 2D-реплей каждого раунда — прямо в браузере.
CS2 match analyzer for FACEIT demos: player ratings, highlights, economy, heatmaps and 2D round replays.

## Возможности

### Аккаунт
- Вход через **Steam** (OpenID) — пароль вводится только на сайте Steam
- Профиль **FACEIT** находится автоматически по Steam ID: аватар, уровень, ELO
- **Монеты**: 20 при регистрации, +3 ежедневный бонус, разбор новой демки — 2 монеты (уже разобранные матчи открываются бесплатно)
- История начислений и списаний

### Матчи
- Последние 20 матчей FACEIT: карта, счёт со своей стороны, K/D, ADR, победа или поражение
- Пометка **«Разобран»** и кнопка **«Загрузить»** прямо в строке матча
- **«Мои матчи»**: загруженные мной и все, где я играл
- Каждый разбор сохраняется и получает свою ссылку `/match/<id>` — ей можно поделиться
- Повторная загрузка той же демки открывается мгновенно
- Большие демки (200+ МБ) загружаются по кусочкам

### Страница матча
- Шапка: карта, счёт, «Победа» / «Поражение»
- **Таблица**: K/D/A, ADR, HS%, **Rating 1.0** (HLTV), **KAST**, **FK–FD**, урон гранатами, матрица дуэлей
- **Раунды**: экономика — пистолетки, эко, форсы, фулл-баи
- **Реплей**: 2D-реплей на радаре — движение, взгляд, HP, оружие, гранаты, трассеры выстрелов, бомба, таблица команд с деньгами, киллфид, скорость 1x–8x
- **Хайлайты**: ACE, 4K, 3K и выигранные клатчи 1v1–1v5
  - 🎬 скачать **видео-клип** момента (MP4/WebM, 1024×1024)
  - 🎮 готовые команды, чтобы открыть момент **в самой CS2**
- **Игрок**: хитмап «где убивал / где умирал», оружие, личные дуэли, лучшие моменты

### Моя статистика
- Средние Rating, K/D, ADR, KAST, HS% и процент побед
- График рейтинга по матчам
- Винрейт и средний рейтинг по картам

### Ещё
- Главная страница (лендинг) и приложение `/app` с вкладками
- Мобильная версия
- Подсветка себя в таблицах и на карте

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

### Ключ FACEIT

Создайте приложение в [FACEIT App Studio](https://developers.faceit.com), получите **серверный** API-ключ и положите его в файл `.env` в корне проекта:

```
FACEIT_API_KEY=ваш_ключ
```

Строку `SESSION_SECRET=...` (секрет для входа через Steam) сервер допишет в `.env` сам при первом запуске.

### Радары карт

Это файлы из игры, поэтому в репозиторий они не входят. Скачиваются один раз:

```bash
pip install awpy
awpy get
mkdir static\maps
Copy-Item "$HOME\.awpy\*\radars\*.png" static\maps\
Copy-Item "$HOME\.awpy\*\map_data.json" static\maps\
```

### Сервер

```bash
uvicorn app:app --reload
```

- http://127.0.0.1:8000 — главная
- http://127.0.0.1:8000/app — приложение

## Публичная ссылка

Сайт можно открыть друзьям через Cloudflare Tunnel — он работает, пока включён компьютер:

```bash
winget install --id Cloudflare.cloudflared
uvicorn app:app --port 8000
cloudflared tunnel --url http://localhost:8000
```

В терминале появится адрес вида `https://....trycloudflare.com`. При каждом запуске он новый.
Не публикуйте ссылку открыто: поиск FACEIT идёт через ваш ключ, а демки разбираются на вашем компьютере.

## 3D-клипы из CS2

`clips3d.py` записывает хайлайты матча (ACE, 4K, 3K, клатчи) прямо из игры — от лица игрока, с настоящей
графикой CS2. Нужен компьютер на Windows с **CS2**, [HLAE](https://www.advancedfx.org/) и
[ffmpeg](https://www.gyan.dev/ffmpeg/builds/) (в PATH). Матч сначала разбирается на сайте как обычно.

```bash
# 1. Сделать сценарий записи (id — из ссылки /match/<id>)
python clips3d.py prepare --match 1a2b3c4d5e6f --demo "D:\demos\match.dem.zst"

#    только свои моменты / только лучшее:
python clips3d.py prepare --match 1a2b3c4d5e6f --demo match.dem --player Nuga006 --types ACE,4K,1v3 --max 5
```

2. Запусти CS2 через HLAE (**File → Launch CS2**), открой консоль `~` и введи `exec nuga_clips` — откроется демка.
   - **F7** — перемотка к следующему хайлайту, камера от лица игрока (по кругу)
   - **F6** — записать все хайлайты подряд. Не трогай ничего, пока в консоли не появится `NUGA: ALL CLIPS DONE`.

3. Собрать ролики:

```bash
python clips3d.py finish --match 1a2b3c4d5e6f
```

Готовые файлы — в `clips3d/<id>/`: по клипу на момент (`01_R07_ACE_Nuga006.mp4`) и `montage.mp4` со всеми подряд.

Параметры `prepare`: `--cs2` (папка игры, если не стандартная), `--fps 60`, `--hud killfeed|full|none`.
Сколько секунд брать до и после момента — константы `PRE_*` / `POST_*` в начале `clips3d.py`.

**Если не работает**
- *Камера не на том игроке* — Valve время от времени ломает команды наблюдателя в демках.
  Скрипт пробует `spec_player_by_accountid` и `spec_lock_to_accountid`; если оба не сработали, обнови HLAE
  (в нём есть свой `mirv_script_spec_lock`) или переключайся на игрока цифрами 1–0 вручную.
- *Нет папок `take0000…` в `clips3d/<id>/raw`* — HLAE не записал: проверь, что CS2 запущена именно через HLAE
  и HLAE свежий (после обновлений CS2 его надо обновлять).
- *Момент начинается не там* — поменяй `PRE_*` / `POST_*` или сдвинь тики в `nuga_clips.cfg`.

## Настройки

В начале `app.py`:

| Константа | По умолчанию | Что значит |
|---|---|---|
| `START_COINS` | 20 | Монеты при регистрации |
| `DAILY_BONUS` | 3 | Ежедневный бонус |
| `ANALYSIS_PRICE` | 2 | Цена разбора новой демки |
| `MAX_UPLOAD` | 700 МБ | Максимальный размер демки |

## Структура

| Файл | Что делает |
|---|---|
| `analyzer.py` | Разбор демки: статистика, рейтинг, раунды, реплей, гранаты, экономика, хайлайты |
| `app.py` | Сервер на FastAPI: загрузка демок, сохранение матчей, FACEIT API, вход через Steam, монеты |
| `static/landing.html` | Главная страница |
| `static/index.html` | Приложение: матчи, статистика, страница матча, реплей, клипы |
| `clips3d.py` | 3D-клипы хайлайтов из CS2 через HLAE + ffmpeg |
| `analyze.py` | Первая версия анализа для терминала: `python analyze.py match.dem.zst` |

Не входят в репозиторий (`.gitignore`):

| Что | Зачем |
|---|---|
| `.env` | Ключ FACEIT и секрет входа |
| `nuga.db` | База пользователей и монет (SQLite) |
| `matches/` | Сохранённые разборы |
| `static/maps/` | Радары карт из awpy |
| `clips3d/` | Записи и готовые 3D-клипы |
| демки `*.dem*` | Большие файлы |

## Технологии

Python, FastAPI, SQLite, [demoparser2](https://github.com/LaihoE/demoparser), pandas, HTML Canvas, MediaRecorder,
[FACEIT Data API](https://docs.faceit.com), Steam OpenID, радары из [awpy](https://github.com/pnxenopoulos/awpy), Cloudflare Tunnel.
