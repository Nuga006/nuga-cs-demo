# Nuga CS Demo

Анализатор демок CS2 с FACEIT: профиль игрока, статистика уровня HLTV, хайлайты, экономика, хитмапы и 2D-реплей раундов.
CS2 demo analyzer: FACEIT player lookup, HLTV-style stats, highlights, economy, heatmaps and 2D round replays on the map radar.

## Возможности

### Игрок FACEIT
- Поиск по нику: аватар, страна, уровень и ELO
- Последние 20 матчей: карта, счёт со стороны игрока, K/D, ADR, победа или поражение
- Ссылка на комнату матча, чтобы скачать демку

### Статистика матча
- Загрузка демки `.dem`, `.dem.gz` или `.dem.zst` через сайт (большие файлы загружаются по кусочкам)
- Таблица по командам: K, D, A, K/D, ADR, HS%
- **Rating 1.0** (формула HLTV), **KAST%**, **FK–FD** (entry-дуэли), **UD** (урон гранатами)
- Матрица дуэлей: кто кого сколько раз убил

### Хайлайты
- Автоматический поиск: **ACE**, **4K**, **3K** и выигранные клатчи **1v1 – 1v5**
- Клик по хайлайту открывает реплей за 3 секунды до момента

### 2D-реплей
- Движение всех игроков по радару карты с плавной анимацией
- Направление взгляда, HP, оружие в руках
- Смоки, молотовы, флешки, HE и трассеры выстрелов
- Бомба: установка, разминирование, взрыв
- Таблица команд в реальном времени: деньги, гранаты, оружие, кто несёт C4
- Счёт по раундам, киллфид, скорость 1x–8x и перемотка

### Экономика
- Стоимость закупки каждой команды по раундам
- Тип закупки: пистолетка, эко, форс, фулл-бай
- Клик по раунду открывает его в реплее

### Разбор игрока
- Хитмап на радаре: где игрок убивал и где умирал
- Оружие: убийства и процент хедшотов
- Личные дуэли против каждого соперника
- Лучшие моменты игрока

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

### Ключ FACEIT

Создайте приложение в [FACEIT App Studio](https://developers.faceit.com), получите **серверный** API-ключ и положите его в файл `.env` в корне проекта:

```
FACEIT_API_KEY=ваш_ключ
```

Файл `.env` закрыт в `.gitignore` — никогда не выкладывайте ключ на GitHub.

### Радары карт

Это файлы из игры, поэтому в репозиторий они не входят. Скачиваются один раз:

```bash
pip install awpy
awpy get
mkdir static\maps
Copy-Item "$HOME\.awpy\*\radars\*.png" static\maps\
Copy-Item "$HOME\.awpy\*\map_data.json" static\maps\
```

### Сервер

```bash
uvicorn app:app --reload
```

Откройте http://127.0.0.1:8000

Скрипт для терминала без сайта:

```bash
python analyze.py match.dem.zst
```

## Публичная ссылка

Сайт можно временно открыть для друзей через Cloudflare Tunnel — он работает, пока включён компьютер:

```bash
winget install --id Cloudflare.cloudflared
uvicorn app:app --port 8000
cloudflared tunnel --url http://localhost:8000
```

В терминале появится адрес вида `https://....trycloudflare.com`. При каждом запуске он новый.
Не публикуйте ссылку открыто: поиск FACEIT идёт через ваш ключ, а демки разбираются на вашем компьютере.

## Структура

| Файл | Что делает |
|---|---|
| `analyzer.py` | Разбор демки: статистика, рейтинг, раунды, реплей, гранаты, экономика, хайлайты |
| `app.py` | Веб-сервер на FastAPI: загрузка демок по кусочкам, разбор, запросы к FACEIT API |
| `static/index.html` | Страница сайта: поиск FACEIT, таблицы, хайлайты, 2D-реплей, экономика, хитмапы |
| `analyze.py` | Первая версия анализа для терминала |
| `.env` | Ключ FACEIT (не входит в репозиторий) |
| `static/maps/` | Радары карт из awpy (не входят в репозиторий) |

## Технологии

Python, FastAPI, [demoparser2](https://github.com/LaihoE/demoparser), pandas, HTML Canvas, [FACEIT Data API](https://docs.faceit.com), радары из [awpy](https://github.com/pnxenopoulos/awpy), Cloudflare Tunnel.
